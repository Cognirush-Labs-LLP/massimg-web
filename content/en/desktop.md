# Desktop version

This web tool runs entirely in your browser and is meant to be independently useful for
quick, everyday compression. For people who need to process very large batches or very
large files without any browser limits, a separate desktop application is also available.

## Which one should I use?

| Need                                        | Web tool | Desktop app |
| ------------------------------------------- | -------- | ----------- |
| Nothing to install                          | Yes      | No          |
| Reduce an image to a given output size      | Yes      | No          |
| Edit an image: rotate, crop                 | Yes      | No          |
| Share finished images to other apps         | Yes      | No          |
| Very large batches                          | No       | Yes         |
| Very large files                            | No       | Yes         |
| Extra input formats (camera formats mainly) | No       | Yes         |
| Output file renaming                        | No       | Yes         |
| Powerful file selection filters             | No       | Yes         |
| Faster compression                          | No       | Yes         |
| Replace the original files                  | No       | Yes         |

## Why use the desktop app?

- No browser memory limits — process much larger batches and larger individual files.
- Runs natively on your computer, outside the browser.
