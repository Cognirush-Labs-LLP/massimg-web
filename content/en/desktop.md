# Desktop version

This web tool runs entirely in your browser and is meant to be independently useful for
quick, everyday compression. For people who need to process very large batches or very
large files without any browser limits, a separate desktop application is also available.

## Why use the desktop app?

- No browser memory limits — process much larger batches and larger individual files.
- Runs natively on your computer, outside the browser.
